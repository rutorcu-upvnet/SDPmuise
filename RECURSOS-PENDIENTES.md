# Recursos pendientes

Ficheros que enlazan las prácticas y aún no están en el repo. La ruta de origen es relativa a **PoliformaT › Recursos › Contenido Lessons**.

La forma más rápida: descarga esa carpeta, descomprímela y ejecuta

```bash
python3 scripts/importar-recursos.py "/ruta/a/Contenido Lessons"
```

El script copia cada fichero a su destino con nombre ASCII y lista los que no encuentre. Si prefieres hacerlo a mano, usa las tablas.
