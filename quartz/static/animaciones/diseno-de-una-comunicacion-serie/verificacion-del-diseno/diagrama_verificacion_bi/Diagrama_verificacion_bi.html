Genera las señales del reloj CLK y de reset para los bloques. A continuación, actuará como si se hubiese tocado la pantalla, proporcionando unas coordenadas X e Y al emulador y activando la señal NEW_COORD para que inicie el proceso de emulación de la pantalla. Una vez el ADC_CONTROL obtenga las coordenadas X e Y, el MFB las comparará con las suministradas al emulador y si coinciden, enviará un mensaje a la consola del ModelSim indicando que la verificación es correcta. Si no coinciden enviará un mensaje de verificación fallida.

MFB.v: Generates the clock and reset signals for the other blocks. After that, it will act as if the screen had been touched, providing the emulator with coordinates X and Y and activating the NEW_COORD signal to force the screen emulation process to start. Once ADC_CONTROL obtains the X and Y coordinates, the MFB with compare them withwith the ones originally provided to the emulator. If they agree, it will send a message to the ModelSim console acknowledging that verification is correct. If they don't, a failed verification message will be output instead.
ADC_CONTROL.v: Design block under verification. It will connect to the touchscreen in order to obtain coordinates X and Y.
EMULE_ADC.vo: Touchscreen emulator. It consists in a functional model of the touchscreen that emulates the behavior of the ADC communication interface.
