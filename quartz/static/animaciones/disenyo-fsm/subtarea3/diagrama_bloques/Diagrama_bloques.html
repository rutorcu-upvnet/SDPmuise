Contador de módulo variable y tamaño programable Este contador se caracteriza porque su tamaño (width_conunter) es parametrizable. El valor al que hay que poner dicho parámetro es 4, de forma que podamos conseguir un contador que pueda implementar un módulo variable entre 2 y 16 dependiendo del valor que introduzcamos en el puerto "entrada" (entre 1 y 15). Counter with variable modulus and programmable size This counter is characterized by the fact that its size (width_counter) is parameterizable. We must use a parameter value of 4, so that we obtain a counter that can run with a variable modulus between 2 and 16 depending on the value of the input "entrada" (between 1 and 15). If all bits of the "entrada" input are set to 0, the output port "fin_cuenta" will behave exactly like the "enable" input, and so this would be equivalent to having a direct connection between the two upper blocks (Terminal Count to Enable).
