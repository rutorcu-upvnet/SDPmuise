Contador de modulo 1056, permite contar el número de pixeles horizontales, o el número de columnas de la pantalla. En cada flanco de subida de la señal de reloj se incrementa la cuenta, indicando así el valor de la coordenada horizontal. La señal de fin de cuenta TC, se utilizará para generar la señal de sincronismo horizontal.
Administrador de Reloj o PLL, genera la señal de reloj de 25 MHz necesaria para la pantalla, a partir del oscilador externo de 50 MHz. Todo el diseño debe funcionar con la señal de 25 MHz generada por el PLL.
Inversor, invierte la señal TC del HCOUNT, para generar la señal de sincronismo horizontal HD.

Contador de modulo 525, permite contar el número de pixeles verticales, o el número de filas de la pantalla. Cada vez que el contador HCOUNT llegue al final de la cuenta, hará que se incremente la cuenta, indicando así el valor de la coordenada vertical. La señal de fin de cuenta TC, se utilizará para generar la señal de sincronismo vertical.
Inversor, invierte la señal TC del VCOUNT, para generar la señal de sincronismo vertical VD.
Generador de la señal DEN, para lo cual utilizará los valores de la columna y la fila suministrados por los contadores HCOUNT y VCOUNT. La señal DEN debe estar activa durante el área de visualización de la pantalla, lo cual corresponde a las coordenadas desde la (216,35) a la (1015,514)
Counter modulo 525. It counts the number of vertical pixels, or screen rows. The count is increased whenever the HCOUNT counter reaches its end-of-count, and determines the current vertical coordinate value. The end-of-count signal TC will be used to generate the vertical sync signal.
Generates the DEN signal using the row and columns values provided by the HCOUNT and VCOUNT counters. The DEN signal must be active within the screen display area, i.e. between the coordinates (216,35) and (1015,514).
Inverter. Inverts the VCOUNT TC signal to obtain the vertical sync signal VD.

Counter modulo 1056. It counts the number of horizontal pixels, or screen columns. The count is increased on each rising edge of the clock, and determines the current horizontal coordinate value. The end-of-count signal TC will be used to generate the horizontal sync signal.
Clock Manager or PLL. Generates the 25 MHz clock signal required by the screen from the external 50 MHz oscillator. The whole design must work with the 25 MHz clock generated by the PLL.
Inverter. Inverts the HCOUNT TC signal to obtain the horizontal sync signal HD.
